# Ejemplos (*Golden Examples*)

Esta carpeta está reservada para almacenar **un curso o sesión de ejemplo completa** (tema genérico y libre de derechos) que muestre la salida esperada de cada etapa del flujo:

```text
examples/sesion-demo/
├── 00-insumos/
│   └── temario-demo.md
├── 01-documento-maestro.md
├── 02-brief-sesion-01.md
├── 03a-ficha-teorica.md
├── 03b-ficha-normativa.md
├── 03c-estrategia-visual.md
├── 03d-presentacion-y-guia.md
├── 03e-capitulo-autonomo.md
├── 04a-informe-auditoria.md
└── 04b-registro-mejoras.md
```

## ¿Cómo contribuir un ejemplo?
Si deseas aportar un ejemplo completo para la comunidad, abre un Pull Request siguiendo [`CONTRIBUTING.md`](../CONTRIBUTING.md) y verifica que no contenga datos privados ni material protegido por derechos de autor.
